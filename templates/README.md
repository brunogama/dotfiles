# Templates

Canonical SOP templates used across consumer repos.

| File | Purpose |
|------|---------|
| `sop-template.md` | Minimal SOP (rule, rationale, scope, procedure, exceptions) |
| `sop-full-template.md` | Full SOP with verification, references, changelog |
| `sop-incident-template.md` | Incident-response runbook variant |

## Usage

1. Copy the smallest template that fits the need.
2. Fill every `<placeholder>`; delete unused optional sections.
