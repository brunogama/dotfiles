# Domain vocabulary

| Term | Definition |
|---|---|
| skill | Reusable technical procedure stored in a harness skill directory. |
| SOP | Governance or process rule stored under `docs/`. |
| candidate | Draft skill that is not active or approved. |
| induction | Generalizing a completed trajectory into a reusable procedure. |
| deduction | Reconstructing an outcome by following only the candidate. |
| promotion | Moving an approved candidate into an active skill directory. |
| peer harness | Claude, Pi, Codex, or another agent runtime using shared repository policy. |
